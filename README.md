## Sobre mim

Desenvolvo software desde 2016, quando comecei criando websites para empresas. Hoje, com mais de 10 anos de experiência, construo sistemas web corporativos de ponta a ponta — da modelagem de dados à interface — com foco em performance, escalabilidade e código sustentável.

Já conduzi a reengenharia de sistemas legados, criei frameworks internos de back-end e front-end e fui responsável por plataformas inteiras, da arquitetura à entrega. No meu dia a dia trabalho com PHP, JavaScript/TypeScript, Java, Python, bancos de dados relacionais, microsserviços, CI/CD, Docker, servidores Linux, AWS e automações com Airflow, N8N e OpenAI.
